### なぜ今、Wiiバランスボードなのか？スマート体重計の魅力

「わざわざWiiバランスボードを使う意味は？」と思われるかもしれませんね。
一般的なスマート体重計は高価だったり、特定のサービスに縛られたりすることがあります。しかし、Wiiバランスボードを流用すれば、**手軽に低コストで**自分だけのスマート体重計を構築できるのです。さらに、Raspberry Pi 4を組み合わせることで、**計測データの自動記録**はもちろん、**クラウドへのアップロード**、**LINEやSlackへの通知**など、既成のスマート体重計ではなかなかできないような、自由でカスタマイズ性の高い機能を実現できます。

Wiiバランスボードには、体重だけでなく、ボードの四隅にかかる圧力も感知するセンサーが内蔵されています。これにより、単なる体重計測にとどまらず、重心のバランスといった**より詳細なデータ**を取得し、健康管理やフィットネスに役立てる可能性も秘めているのです。

### 準備するもの：プロジェクトの土台を固める

このプロジェクトを始めるにあたり、いくつか準備する機材があります。

*   **Wiiバランスボード**: 当然ながら必須です。中古品でも問題ありません。
*   **Raspberry Pi 4 (推奨)**: Bluetooth機能内蔵のモデルなら何でもOKですが、処理能力の高さからPi 4をおすすめします。
*   **microSDカード**: OSをインストールするために必要です。（16GB以上推奨）
*   **Raspberry Pi 4用電源アダプター**: 安定した動作のために純正品または品質の良いものを。
*   **Wi-Fi環境**: ネットワーク接続とデータ転送に必要です。
*   **PC (セットアップ用)**: microSDカードへのOS書き込みなどで使います。

### Raspberry Pi 4のセットアップ：OS導入からBluetooth接続まで

まずはRaspberry Pi 4の基本的なセットアップから始めましょう。

#### 1. Raspberry Pi OSのインストール

Raspberry Pi Imagerを使って、microSDカードに**Raspberry Pi OS Lite (64-bit)**をインストールします。ヘッドレス運用（モニターなしでの操作）を前提とするため、Lite版が軽量でおすすめです。

1.  Raspberry Pi ImagerをPCにダウンロード・インストールします。
2.  Imagerを起動し、「OSを選ぶ」で「Raspberry Pi OS (other)」から「Raspberry Pi OS Lite (64-bit)」を選択します。
3.  「ストレージを選ぶ」でmicroSDカードを選択します。
4.  右下の歯車アイコンをクリックし、SSH有効化、ユーザー名・パスワード設定、Wi-Fi設定を行っておくと、初期セットアップが非常に楽になります。
5.  「書き込む」をクリックし、OSの書き込みが完了するのを待ちます。

#### 2. 初回起動とSSH接続

書き込みが完了したmicroSDカードをRaspberry Pi 4に挿入し、電源を入れます。設定したWi-Fi経由でネットワークに接続されるはずです。

PCからSSHで接続します。コマンドプロンプトやターミナルを開き、以下のコマンドを実行してください。

```bash
ssh <ユーザー名>@<Raspberry PiのIPアドレス>
```

IPアドレスが不明な場合は、ルーターの管理画面を確認するか、`arp -a` コマンドなどで探します。

#### 3. システムの更新とBluetooth環境の準備

SSH接続後、まずはシステムを最新の状態に更新しておきましょう。

```bash
sudo apt update
sudo apt upgrade -y
```

次に、Bluetoothデバイスとの連携に必要なパッケージをインストールします。

```bash
sudo apt install bluetooth bluez libbluetooth-dev python3-pip -y
```

### Wiiバランスボードとのペアリング

いよいよWiiバランスボードとRaspberry Pi 4をペアリングします。WiiバランスボードはBluetooth HIDデバイスとして動作します。

1.  **Wiiバランスボードをペアリングモードにする**:
    Wiiバランスボードの電源を入れ（多くの場合、乗ると自動でONになります）、ボード裏側の赤い**SYNCボタン**を長押しします。ボード前面の青いLEDが点滅し始めれば、ペアリングモードに入っています。

2.  **Raspberry Piでデバイスをスキャンする**:
    Raspberry Piのターミナルで `bluetoothctl` コマンドを実行します。

    ```bash
    bluetoothctl
    ```

    `bluetoothctl`プロンプトに入ったら、以下のコマンドでスキャンを開始します。

    ```bash
    [bluetooth]# scan on
    ```

    数秒待つと、Wiiバランスボードが表示されるはずです。通常、「Nintendo RVL-WBC-01」のような名前で見つかります。表示されたデバイスのMACアドレスを控えておきます（例: `XX:XX:XX:XX:XX:XX`）。

    スキャンを停止します。

    ```bash
    [bluetooth]# scan off
    ```

3.  **ペアリングと信頼**:
    見つけたWiiバランスボードとペアリングし、信頼するデバイスとして登録します。

    ```bash
    [bluetooth]# pair <WiiバランスボードのMACアドレス>
    [bluetooth]# trust <WiiバランスボードのMACアドレス>
    [bluetooth]# connect <WiiバランスボードのMACアドレス>
    ```

    `pair` コマンドでPINコードを要求されることがありますが、Wiiバランスボードの場合は通常不要です。接続が成功すると、WiiバランスボードのLEDが点滅から点灯に変わるはずです。

    `bluetoothctl`プロンプトを終了します。

    ```bash
    [bluetooth]# quit
    ```

### センサーデータの取得と処理：Pythonスクリプトで体重を読み取る

ペアリングが完了したら、いよいよWiiバランスボードからセンサーデータを読み取ります。Pythonを使って、これを実現しましょう。いくつかのライブラリが存在しますが、ここでは一般的な概念を説明し、`python-wiiboard`や`pywiiboard`といったライブラリの利用を視野に入れます。これらのライブラリは、WiiバランスボードからのBluetooth通信を解析し、四隅のロードセルから得られる生のデータを扱いやすい形に変換してくれます。

#### 1. 必要なPythonライブラリのインストール

Wiiバランスボードのデータを扱うためのライブラリをインストールします。ここでは例として`evdev`を挙げます。（直接`pip install python-wiiboard`でインストールできない場合、GitHubからクローンして手動でインストールする必要があるかもしれません。詳細な手順はライブラリのREADMEを参照してください。）

```bash
pip3 install evdev
# 例えば、もし特定のwiiboardライブラリがあるなら
# pip3 install python-wiiboard
```
※`evdev`は多くのHIDデバイスを扱う際に有用です。Wiiバランスボードの特定のライブラリが見つからない場合、低レベルな`bluetooth`ライブラリと`evdev`を組み合わせて自作することも可能ですが、ここでは既存ライブラリがある前提で進めます。

#### 2. サンプルスクリプトの作成

以下は、Wiiバランスボードからデータを読み取り、体重を表示するPythonスクリプトの概念的な例です。具体的な実装は、使用するライブラリによって異なります。

```python
import time
# from wiiboard import Wiiboard # wiiboardライブラリのインストールが必要

# WiiバランスボードのMACアドレスを指定 (例として記載、実際にはMACアドレスを指定)
WIIBOARD_MAC_ADDRESS = "XX:XX:XX:XX:XX:XX" # 上記で控えたMACアドレスに置き換えてください

# これはあくまで概念的なWiiboardクラスの例です
class MockWiiboard:
    def __init__(self, mac_address):
        self.mac_address = mac_address
        self.is_connected = True # 簡略化のため常に接続済みと仮定

    def get_mass(self):
        # 実際のライブラリではセンサーからデータを読み取る
        # ここでは仮の値を返す
        import random
        if random.random() < 0.2: # 20%の確率で誰も乗っていない状態
            return 0.0
        return 50.0 + random.uniform(-2.0, 2.0) # 適当な体重を生成

    def disconnect(self):
        self.is_connected = False

def main():
    print(f"Wiiバランスボード ({WIIBOARD_MAC_ADDRESS}) に接続中... (概念例)")
    # 実際のコードでは以下のようにWiiboardクラスをインスタンス化
    # board = Wiiboard(WIIBOARD_MAC_ADDRESS)
    board = MockWiiboard(WIIBOARD_MAC_ADDRESS) # 概念的なMockオブジェクトを使用

    if not board.is_connected:
        print("Wiiバランスボードへの接続に失敗しました。MACアドレスが正しいか、ボードがペアリングモードか確認してください。")
        return

    print("接続成功！ボードに乗って体重を計測してください。")
    print("Ctrl+Cで終了します。")

    try:
        while True:
            # 最新のセンサーデータを取得
            weight = board.get_mass() # 総体重を取得
            
            if weight > 0:
                print(f"体重: {weight:.2f} kg")
            else:
                print("ボードは空です。")
            
            time.sleep(1) # 1秒ごとに更新
            
    except KeyboardInterrupt:
        print("\nプログラムを終了します。")
    finally:
        board.disconnect()
        print("Wiiバランスボードとの接続を切断しました。")

if __name__ == "__main__":
    main()
```
このスクリプトはあくまで概念であり、実際に動作させるには`wiiboard`ライブラリの正確な使用方法に従う必要があります。もし`python-wiiboard`が直接使えない場合は、`bluez`と`evdev`を組み合わせた低レベルなBluetooth HIDイベントの読み取りが必要になりますが、これは少し高度な内容になるため、まずは既存のライブラリを探すことをお勧めします。

### スマート体重計として進化させる：データの可視化と連携

体重が計測できるようになったら、次は「スマート」な機能を追加していきましょう。

*   **データの自動記録**: 取得した体重データをCSVファイルに保存したり、SQLiteなどのローカルデータベースに記録したりします。タイムスタンプと合わせて記録することで、日々の変化を追跡できます。
*   **クラウド連携**: 取得したデータをGoogle Sheets APIや、AWS IoT Core、MQTTブローカーなどを介してクラウドサービスに送信します。これにより、外出先からでも体重データを閲覧できるようになります。
*   **通知機能**: 特定の体重を超えた、または目標体重に達した際に、LINE NotifyやSlack Incoming Webhooksなどを利用して通知を飛ばすことができます。
*   **WebUIの構築**: Raspberry Pi上でWebサーバー（FlaskやDjangoなど）を動かし、計測データをグラフ表示するようなシンプルなWebインターフェースを構築するのも面白いでしょう。

### 課題と発展性

*   **キャリブレーション**: Wiiバランスボードは元々ゲーム用途のため、正確な体重計としてのキャリブレーションが必要です。既知の重さ（例: ペットボトルなど）を乗せて、測定値のオフセットを調整することで精度を高められます。
*   **電源管理**: 常時稼働させる場合は、安定した電源供給と、Wiiバランスボードのバッテリー管理も考慮に入れる必要があります。
*   **自動起動**: Raspberry Piの起動時に、上記のPythonスクリプトが自動的に実行されるように設定（`systemd`サービスなど）すると、よりスマートな運用が可能です。
