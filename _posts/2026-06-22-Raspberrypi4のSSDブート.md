### はじめに：Raspberry Pi 4とSSDブートの魅力

皆さん、こんにちは！独楽鼠吾郎です。

Raspberry Pi 4（通称「ラズパイ4」）は、その小ささに似合わず非常にパワフルなシングルボードコンピューターですが、唯一の弱点として挙げられるのが、OSの起動やデータの読み書きに使用するmicroSDカードの速度と耐久性です。microSDカードは手軽で便利ですが、頻繁な書き込みには弱く、時としてパフォーマンスのボトルネックにもなりがちです。

そこで今回ご紹介するのが「**SSDブート**」。ラズパイ4にSSDを接続してOSを起動させることで、劇的な速度向上と耐久性の強化を実現できます。まるで別のマシンになったかのような快適さを手に入れることができる、まさにラズパイ4使いの最終兵器とも言えるでしょう。

しかし、SSDブートにはいくつかの落とし穴があり、時に「繋いだのに起動しない！」といったトラブルに見舞われることも少なくありません。本記事では、そんなラズパイ4のSSDブートについて、セットアップ手順からよくあるトラブルシューティングまで、私の経験を交えながら徹底的に解説していきます。

### なぜSSDブートを選ぶのか？そのメリットとは

SSDブートのメリットは数多くありますが、主なものは以下の通りです。

*   **劇的な速度向上**: microSDカードに比べて、OSの起動時間、アプリケーションの読み込み、ファイル操作など、あらゆる面で高速化を実感できます。
*   **高い耐久性**: SSDはmicroSDカードよりも書き換え回数に強く、長期間にわたる安定稼働が期待できます。特にサーバー用途など、頻繁なデータ書き込みが発生する環境では大きなアドバンテージとなります。
*   **静音性と低発熱**: 可動部品がないため、ノイズがなく、発熱もHDDに比べて低い傾向にあります。

### 準備するもの

SSDブートを始めるにあたり、以下のものを用意しましょう。

*   **Raspberry Pi 4**: 言わずもがな本体です。
*   **USB-SATA変換アダプタ**: SSDをUSBポートに接続するために必要です。**UASP（USB Attached SCSI Protocol）対応**のものを選ぶと、さらに高速なデータ転送が可能です。相性の問題も出やすい部分なので、実績のある製品を選ぶことをお勧めします。
*   **SSD**: 容量は用途によりますが、一般的なOSとアプリケーションであれば120GB〜250GB程度で十分でしょう。
*   **高品質な電源アダプタ**: ラズパイ4本体に十分な電力を供給できるもの（公式の5.1V 3Aなど）。
*   **（場合によって）セルフパワーUSBハブ**: 電源供給が不安定なSSDや、複数のUSB機器を接続する場合に役立ちます。

上記は、私が実際に試した際に役立ったセルフパワーUSBハブの一例です。特に、容量の大きなSSDや、USB-SATA変換アダプタによっては、ラズパイ4本体からの電力供給だけでは不足することがあります。起動が不安定な場合や、SSDが認識されない場合は、ぜひ試してみてください。

### Step 1: Raspberry Pi 4のEEPROMを最新にする

ラズパイ4がUSBブートに対応したのは、EEPROMファームウェアのアップデートによってです。古いファームウェアのままではSSDから起動できないため、必ず最新の状態にしておきましょう。

1.  **microSDカードでラズパイを起動**: まずは通常のmicroSDカードにRaspberry Pi OSを書き込み、ラズパイ4を起動します。
2.  **EEPROMのアップデートを確認・実行**: ターミナルを開き、以下のコマンドを実行します。

    ```bash
    sudo apt update
    sudo apt full-upgrade
    sudo rpi-eeprom-update
    ```

    `sudo rpi-eeprom-update`を実行すると、現在のファームウェアバージョンと利用可能な最新バージョンが表示されます。もし更新が必要な場合は、以下のコマンドでアップデートできます。

    ```bash
    sudo rpi-eeprom-update -a
    ```
    アップデートが完了したら、ラズパイを再起動してください。
    `vcgencmd bootloader_version`でブートローダーのバージョンを確認できます。`VL805`チップのファームウェアも同時にアップデートされます。

3.  **ブート順序の設定（任意）**: デフォルトではSDカードからのブートが優先されますが、完全にSSDブートに移行したい場合は、ブート順序を変更できます。
    `sudo raspi-config`を実行し、「6 Advanced Options」→「A6 Boot Order」で「B2 USB Boot」を選択します。これにより、USBからの起動が最優先されるようになります。

### Step 2: SSDにRaspberry Pi OSを書き込む

次に、用意したSSDにRaspberry Pi OSを書き込みます。この作業は別のPC（Windows, macOS, Linuxなど）で行うのが一般的です。

1.  **Raspberry Pi Imagerのダウンロード**: 公式サイトから「Raspberry Pi Imager」をダウンロードし、インストールします。
2.  **SSDをPCに接続**: USB-SATA変換アダプタを使ってSSDをPCに接続します。
3.  **OSの選択**: Raspberry Pi Imagerを起動し、「OSを選ぶ」から希望のRaspberry Pi OSを選択します（通常は「Raspberry Pi OS (64-bit)」または「Raspberry Pi OS Full (64-bit)」が良いでしょう）。
4.  **ストレージの選択**: 「ストレージを選ぶ」から、**間違えずに**PCに接続したSSDを選択します。ここを誤ると、PCの内蔵ドライブを消去してしまう危険があるので、慎重に確認してください。
5.  **書き込み**: 「書き込む」をクリックし、OSの書き込みを開始します。完了するまでしばらく待ちます。

### Step 3: ラズパイ4にSSDを接続して起動！

OSの書き込みが完了したら、いよいよラズパイ4にSSDを接続して起動してみましょう。

1.  **ラズパイ4の電源を切る**: 必ず電源を切ってから作業を行ってください。
2.  **SSDをUSB 3.0ポートに接続**: 書き込み済みのSSDを、ラズパイ4の**青色のUSB 3.0ポート**のどちらかに接続します。
3.  **（microSDカードを取り外す）**: もしSDカードからの起動を完全にやめるなら、ここでmicroSDカードを抜いておきます。ブート順序をUSB優先にしていても、SDカードが挿入されているとそちらから起動してしまう場合があるためです。
4.  **電源ON**: ラズパイ4の電源を入れます。

これで無事にSSDから起動すれば成功です！OSの起動速度やアプリケーションの応答性が向上していることを体感できるでしょう。

### SSDブートで起動しない時のトラブルシューティング

「よし、これで爆速ラズパイだ！」と意気込んだものの、「あれ、起動しない…」となることは、実は珍しくありません。私自身も何度か経験しています。

{% include link-card.html url="https://qiita.com/yoshiki9636/items/223d835b161f84335cde" title="Raspberrypi4のSSDブート（関連アイテム）" context="Raspberrypi4の3.0ボートにブート環境をセットアップしたSSDを接続したが起動に失敗した。" %}

この方も同様の経験をされているようですね。SSDをUSB 3.0ポートに繋ぎ、ブート環境もセットアップしたはずなのに起動に失敗する。このような状況に遭遇した場合、以下の点を順に確認してみてください。

#### 1. 電源不足は最大の敵！

最も多い原因が、ラズパイ4本体またはSSDへの**電源供給不足**です。

*   **ラズパイ4本体の電源**: 公式の5.1V 3Aアダプタを使用していますか？安価な汎用アダプタでは、ピーク時に電力不足となることがあります。
*   **SSDへの電力**: 一部のSSDやUSB-SATA変換アダプタは、ラズパイ4のUSBポートからの電力だけでは足りない場合があります。この場合、前述したように**セルフパワーUSBハブ**を介してSSDを接続することで解決することが多いです。特に、複数のUSB機器を接続している場合は、電力不足のリスクが高まります。

#### 2. SSD/USB-SATA変換アダプタの相性問題

意外と見落としがちなのが、SSDやUSB-SATA変換アダプタとラズパイ4の相性です。

*   **UASP対応**: 高速なUASP対応のアダプタは推奨されますが、一部のアダプタはラズパイ4のカーネルと相性が悪い場合があります。特定のチップセット（例えばJMicronの一部）で報告されているケースもあります。もし手元に別のアダプタがあれば、試してみる価値はあります。
*   **SSDのメーカー・モデル**: 特定のSSDモデルがラズパイ4との組み合わせで起動しないという報告も散見されます。可能であれば、実績のあるSSDやアダプタの組み合わせを試すのが安全です。

#### 3. EEPROMは本当に最新？

Step 1でEEPROMをアップデートしたはずでも、念のためもう一度確認しましょう。

*   `sudo rpi-eeprom-update`でバージョンを確認し、必要であれば再度アップデートしてください。
*   ファームウェアのバージョンによっては、USBブートが完全にサポートされていないものもあります。

#### 4. ブート順序の設定は正しいか？

`sudo raspi-config`で設定したブート順序を再度確認します。もしSDカードが挿入されている場合は、一旦抜いてみてUSBブートを強制的に試すのも有効です。

#### 5. OSイメージの破損や書き込みミス

稀ですが、OSイメージのダウンロード中にファイルが破損したり、書き込み中にエラーが発生したりする可能性もゼロではありません。
もう一度ImagerでOSを書き込み直してみるのも一つの手です。

### まとめ：諦めずに試行錯誤を！

ラズパイ4のSSDブートは、その快適さから一度体験するとmicroSDカードには戻れなくなるほど魅力的です。もし起動に失敗しても、今回紹介したトラブルシューティングを参考に、諦めずに試行錯誤してみてください。

特に「電源」と「USB-SATA変換アダプタの相性」は、トラブル解決の鍵となることが多いです。原因を一つずつ潰していくことで、きっとあなたも爆速ラズパイライフを手に入れられるはずです。
