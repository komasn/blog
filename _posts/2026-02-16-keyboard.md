スマホがあれば、ちょっとしたコードのレビューや修正ならノートPCを持ち歩かなくても対応できます。
外付けキーボードを組み合わせると快適度がさらに上がります。

しばらくこの環境で作業していますが、本当に快適です

## スマホでの作業環境 — 主な選択肢

### a) GitHub 公式アプリ
- リポジトリの閲覧・PR レビュー・マージがスマホから手軽にできる
- 通知連携で変更をすぐ把握できる
- モバイル向けに最適化された UI で操作しやすい

### b) Spck Editor（Android エディタ）
- ローカルファイルの編集に強く、動作が軽快
- ファイルの作成・修正が素早くできる
- オフラインでも編集可能

### c) code-server + ブラウザ
- 本物の VS Code に近い環境をスマホのブラウザから利用できる
- 拡張機能や豊富な IDE 機能をそのまま使える
- 自宅サーバや VPS に立てておけばどこからでもアクセス可能

### d) GitHub Codespaces
- クラウド上にフル機能の開発環境を即座に用意できる
- `devcontainer` で設定を共有でき、チームで一貫した環境を保てる
- GitHub Copilot 等との連携がスムーズ

## 外付けキーボードとモバイル作業の組み合わせ

スマホ単体でのタッチ入力は長文作業に向きません。**折りたたみ式 Bluetooth キーボード**を一枚カバンに忍ばせておくだけで、作業効率が大幅に向上します。折りたたみ式はコンパクトで持ち運びやすく、広げるとフルサイズに近いキーピッチになる製品もあります。

### 購入時チェックリスト

- [ ] Bluetooth 接続対応（USB レシーバー不要のものが持ち運びに便利）
- [ ] 折りたたみ時のサイズがポケットやポーチに収まるか
- [ ] キーピッチが広めで長文入力に耐えられるか
- [ ] バッテリー持続時間が十分か
- [ ] スマホスタンド機能が内蔵されているか（または別途スタンドを用意するか）

## まとめ

まずは**折りたたみ式キーボードを試してみるのが無難**です。安価なものでも快適さが大きく変わります。キーボードを確保したうえで、用途に合わせて GitHub 公式アプリ・Spck Editor・code-server・Codespaces を使い分けると、スマホだけでも十分な開発体験が得られます。
